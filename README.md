# ZenVolt website

Run the website and shared media backend:

```powershell
npm start
```

Open `http://localhost:3000`. Uploaded product images and videos are saved in `media/`, and the shared catalog is saved in `data/products.json`.

Other devices can see the same catalog by using the hosted server URL, or `http://<this-computer-LAN-IP>:3000` while connected to the same network.
